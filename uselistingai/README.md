# UseListingAI — Listing Analysis Plugin

AI-powered real estate listing analysis for Claude Code.

## What it does

Analyzes any residential real estate listing URL and returns a complete intelligence report:

- **Listing strength score** out of 10
- **Content gaps** — specific missing information affecting buyer decisions  
- **Price positioning** — market assessment using local knowledge
- **Fair Housing compliance scan**
- **AI market commentary** — specific actionable advice

## Supported sites

Redfin, Century 21 (C21), REMAX, Zillow, Homes.com, and most major listing sites.

## Usage

Once installed, paste any listing URL:

```
Analyze this listing: https://www.c21.ca/listing/...
```

Or:

```
Why isn't this listing getting showings? https://www.redfin.com/...
```

## Install

```
/plugin install uselistingai@claude-plugins-official
```
